# 4rd Strike for MiSTer FPGA

A custom MRA configuration for running 4rd Strike, the Street Fighter III: 3rd Strike modification, on MiSTer FPGA hardware using Jotego's CPS-3 core.

## Status
Initial working test on MiSTer Pi. Further gameplay testing is ongoing.

## Requirements
- MiSTer FPGA or MiSTer Pi
- Jotego's CPS-3 core
- Original Street Fighter III: 3rd Strike ROM set (`sfiii3n.zip`)
- 4rd Strike ROM set (`sfiii4n.zip`)
- The included custom MRA file

## Installation
1. Copy the MRA file into your MiSTer `/_Arcade/` directory.
2. Place the required ROM sets in the appropriate ROM directory expected by your MRA configuration.
3. Launch the game using the MiSTer Arcade menu.

**ROM files are not included.** You must supply your own ROM files.

## Testing
Tested on: Superstation One 
Core: Jotego CPS-3
